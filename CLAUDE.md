## Docs site

- Every release tag pushes a `docs: sync to vX.Y.Z` commit to main (deploy.yml then redeploys the site), so run `git pull` before the next `npm run publish:full`.
- `website/src/pages/**` is maintainer-owned; `website/docs/**` is regenerated by CI.
- Installing the Docs site (`npm install --prefix website`) needs the home LAN and `VERDACCIO_CI_TOKEN` exported; without it only `@internal/*` fails, with an auth error.
