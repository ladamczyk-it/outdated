# Outdated

An extension of `npm outdated`: the same table, plus last publish date, deprecation, staleness and repository links. It uses the npm CLI under the hood.

> Historical docs for **`@ladamczyk/outdated` v1.x**, verified against **v1.1.2**. For the current release, see the latest docs. See [`CHANGELOG.md`](https://github.com/ladamczyk-it/outdated/blob/v1.1.2/CHANGELOG.md) to verify accuracy.

## Installation

```bash
npm install --save-dev @ladamczyk/outdated@1
```

## Usage

Run it directly, no install needed:

```bash
npx -y @ladamczyk/outdated@1 [options]
```

Or install globally and use the `outdated` command:

```bash
npm i -g @ladamczyk/outdated@1
outdated [options]
```
